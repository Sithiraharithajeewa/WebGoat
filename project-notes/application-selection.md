# IE3142 DevOps Security – Application Selection

## Selected Application

Application: OWASP WebGoat

Application Type: Intentionally Vulnerable Web Application

Technology: Java / Spring Boot

Components: Web application + embedded database

Containerisation: Docker

Official Docker Image: webgoat/webgoat

Purpose:
OWASP WebGoat is an intentionally vulnerable educational
web application used to demonstrate and learn common
web application security vulnerabilities.

Reason for Selection:
WebGoat is explicitly included in the IE3142 assignment's
pre-vetted list of intentionally vulnerable applications.
It provides a suitable environment for vulnerability
demonstration, secure coding remediation, SAST analysis,
Docker containerisation and DevSecOps security automation.
